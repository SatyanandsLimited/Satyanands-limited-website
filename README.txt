IMPORTANT STATIC-SITE NOTE
The admin page stores changes in the browser's local storage. To publish a changed price/new product for all customers on a static host such as GitHub Pages:
1. Open admin.html and sign in.
2. Make changes.
3. Click Export Product Data.
4. Replace the website's product.js with the downloaded product.js.
5. Commit/publish the updated file.

The customer site never displays a link to admin.html.
